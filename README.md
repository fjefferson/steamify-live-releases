# Steamify Live — Official Releases

Official public releases and installers for **Steamify Live** and **Steamify Cam** (OBS Studio plugins).

- 🌐 **Website & Download:** [https://live.steamify.com.br](https://live.steamify.com.br)
- 📦 **Latest Releases:** Check the [Releases](https://github.com/fjefferson/steamify-live-releases/releases) page to download the Windows installer (`.exe`).

## What's Included

- **Steamify Live** — Native C++ multistreaming plugin for OBS Studio (0% extra GPU load), unified cross-chat, unified events dock, game presets & cloud backup.
- **Steamify Cam** *(Optional in installer)* — Webcam studio filters for OBS Studio: **Google Meet Beauty**, Instagram-style presets, **150+ 3D `.cube` LUTs**, and AI filter generator powered by your Steamify Live AI key.
